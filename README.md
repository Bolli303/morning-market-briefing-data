# morning-market-briefing-data

Datendatei `briefing.json` für das Dashboard [morning-market-briefing.pplx.app](https://morning-market-briefing.pplx.app).

- Wird werktags automatisch durch das Perplexity-Projekt „Morning Market Briefing“ aktualisiert.
- Eine neue Version wird nur hochgeladen, wenn sie die vollständige Prüfung (Schema V1) besteht. Sonst bleibt die letzte erfolgreiche Version bestehen.
- Marktverständnis, kein Trading-Briefing, keine Anlageberatung.
